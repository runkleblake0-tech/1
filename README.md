# SEB Integration Hub

This is a minimal Vite static site for the SEB Integration Hub used for demonstrations and static deployment.

Local development

1. Set up Node 18+ and npm
2. npm install
3. npm run dev

Build

- npm run build

Deploy

The repository includes a GitHub Action to build and deploy the `dist/` folder to GitHub Pages automatically on pushes to `main`.

You can check the workflow under: .github/workflows/gh-pages.yml

Pages site (when published) will be available at:
https://runkleblake0-tech.github.io/1/
